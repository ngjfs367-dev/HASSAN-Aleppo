# حَسَن — Cinematic Remotion Documentary

فيديو وثائقي عربي قصير مدته **30 ثانية** عن حسن، بنسبة **16:9** ودقة **1920×1080** وبأسلوب سينمائي هادئ.

## المواصفات

- 1920×1080 Full HD
- 30 FPS
- 900 إطار / 30 ثانية
- 4 مشاهد
- نصوص عربية RTL
- حركة كاميرا بسيطة: zoom / pan / pull-back
- انتقالات ناعمة
- vignette + letterbox + film grain
- إخراج MP4 / H.264
- لا يعتمد على ملف صوتي مفقود، لذلك يمكن تنفيذ الرندر مباشرة

## المشاهد

1. **0–7 ثوانٍ:** افتتاحية باسم «حَسَن»
2. **7–15 ثانية:** محاولة تغيير الحياة رغم الصعوبات
3. **15–24 ثانية:** الطموح، التفكير، العمل، والاستمرار
4. **24–30 ثانية:** «الحكاية لسا ما خلصت.»

## التشغيل

```bash
npm install
npm start
```

## الرندر إلى MP4

```bash
npm run render
```

الملف الناتج:

`out/hasan_documentary.mp4`

## الأصول

الخلفيات الحالية تجريبية ومولدة داخل React/CSS، ولا تحتاج إلى ملفات خارجية.

يمكن لاحقاً إضافة صور أو فيديوهات حقيقية داخل:

- `public/images/`
- `public/video/`

ويمكن إضافة موسيقى اختيارية داخل:

- `public/audio/`

**ملاحظة:** ملف `public/audio/hasan-documentary.mp3` غير مطلوب حالياً؛ تم إزالة الاعتماد الإجباري عليه حتى لا يفشل الرندر.

## البنية

- `src/Root.tsx` — إعداد 1920×1080، 30 FPS، 900 إطار
- `src/Composition.tsx` — تركيب المشاهد
- `src/components/Scene1.tsx` إلى `Scene4.tsx` — المشاهد
- `src/components/FilmGrain.tsx` — المعالجة السينمائية
- `remotion.config.ts` — إعداد H.264 و yuv420p
